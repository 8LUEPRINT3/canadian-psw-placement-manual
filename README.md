## 🧭 Quick reference

- **Always acknowledge first, stay in scope, document facts, escalate.**
- **DARP** = Data → Action → Response → Plan.
- **Never** diagnose, administer medication, change the care plan, or leave a client in distress.
- **Mandatory reporting:** LTC → `1-866-434-0144` · Retirement → `1-800-361-7254` · OPG&T → `1-800-366-0335`.
